# Contributing

Small, focused improvements are welcome for discussion once public contributions
open. Describe the problem before starting a large feature; a proposal is not a
commitment to accept it. AI-assisted contributions are welcome when reviewed and
understood by the contributor. Explain how the result was tested.

Preserve offline operation, explicit saves, old-file compatibility, conflict checks,
backup/restore, compact layouts and separate estimated/actual costs. Use synthetic
fixtures. Do not include customer records, machine paths, credentials or dependency
folders. Run python build_release.py before submitting a change and identify any
native Windows or print checks not performed. See docs/MAINTENANCE.md.

Submit only contributions you have the right to share under this project’s MIT
license. Retain applicable third-party notices and identify borrowed material.
