# Support

RōM is a personal project maintained as time permits. No response time, update
schedule or feature implementation is promised. Support is through repository
issues when enabled; direct messages and custom installation assistance are not guaranteed.

For a bug, include the app version, Windows/Python/browser versions, concise steps,
expected result and actual result. Use a fictional trip to reproduce it. Crop
screenshots to remove names, addresses, local paths, booking references and other
private information. Do not upload your Data folder or full backups.

For startup problems, try Start-App-Diagnostics.bat and inspect the local error log.
Review logs before sharing even a small excerpt. Back up before applying updates.

Do not post credentials or exploitable security details in a public issue. Until a
private reporting channel is configured, no private vulnerability-reporting channel
is advertised by this candidate. The maintainer should configure one before launch.
